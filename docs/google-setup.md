# Подключение Google

Календарь, конспекты Granola, посты и ежедневная копия в Google Drive работают через маленький скрипт Apps Script. Он живёт внутри вашей таблицы и выполняется от вашего имени. Проект в Google Cloud, сервисный аккаунт и ключи не нужны.

Займёт минут десять.

## 1. Таблица

Таблица «Уроки: конспекты и посты» уже создана в вашем Google Drive. В ней три листа:

| Лист | Что там | Кто пишет |
|---|---|---|
| Конспекты | конспект каждого урока из Granola | вечерняя задача Claude |
| Посты | черновики постов для Instagram | недельная задача Claude |
| Журнал | что сделала каждая задача | обе задачи |

Порядок колонок не меняйте: скрипт читает их по номерам.

## 2. Скрипт

1. Откройте таблицу и выберите **Расширения → Apps Script**.
2. Удалите пустую функцию, вставьте целиком файл `google/Code.gs` из репозитория и нажмите сохранить. Имя проекта любое, например «Уроки: мост».
3. Вверху выберите функцию **setup** и нажмите **Выполнить**. Google попросит доступ к календарю, таблицам и Drive. Появится окно «Приложение не проверено»: это ваш собственный скрипт, нажмите **Дополнительные настройки → Перейти к проекту** и разрешите.
4. Внизу откроется журнал выполнения со строкой `Токен для GOOGLE_SCRIPT_TOKEN: …`. Скопируйте токен.
5. По желанию выберите функцию **checkCalendar** и выполните её. В журнале появятся уроки на две недели вперёд: значит, календарь читается.

## 3. Веб-приложение

1. **Начать развертывание → Новое развертывание**, тип **Веб-приложение**.
2. «Выполнять от имени»: **Я**. «У кого есть доступ»: **Все**.
3. Нажмите **Начать развертывание** и скопируйте URL. Он заканчивается на `/exec`.

Почему доступ «Все»: сервер Vercel обращается к скрипту без входа в Google. Без правильного токена скрипт отвечает только `forbidden` и ничего не показывает.

## 4. Vercel

1. Проект **payment-tracker-v02 → Settings → Environment Variables**.
2. Добавьте две переменные для Production:

| Переменная | Значение |
|---|---|
| `GOOGLE_SCRIPT_URL` | URL из шага 3 |
| `GOOGLE_SCRIPT_TOKEN` | токен из шага 2 |

3. **Deployments → последний деплой → Redeploy**.

## 5. Проверка

Откройте приложение и разверните **Настройки и резервные копии**. Там должна быть строка «Google подключён». На главной появится блок «Ближайшие уроки».

Дальше там же нажмите **Загрузить историю из календаря**. Приложение найдёт уроки, покажет, кто из людей в календаре какой ученик, и только после вашего подтверждения добавит их в историю. Балансы при этом не меняются.

## Если что-то пошло не так

| Сообщение в приложении | Что делать |
|---|---|
| Google не подключён | на Vercel нет одной из двух переменных или проект не передеплоен |
| Apps Script отклонил токен | токен на Vercel не совпадает с токеном скрипта: запустите setup ещё раз и скопируйте заново |
| Apps Script ответил не данными | у веб-приложения доступ не «Все»: исправьте в «Управление развертываниями» |
| В Apps Script не задан токен | в скрипте не запускали setup |
| Ошибка в Apps Script | текст ошибки пришёл из скрипта; чаще всего переименован лист или колонка |

Если поменяете код скрипта, обновите развертывание: **Начать развертывание → Управление развертываниями → карандаш → Версия: новая → Начать развертывание**. URL остаётся прежним.

Утёк токен: запустите в скрипте функцию **rotateToken** и вставьте новый токен на Vercel.

## Что скрипт отдаёт наружу

Только то, что нужно приложению: название события, время начала и конца, адреса участников, строки листов «Конспекты» и «Посты». Описания событий с телефонами учеников не отдаются никогда.

## Задачи по расписанию

Их выполняет Claude, они создаются в разделе запланированных задач claude.ai, а не в этом репозитории.

- **Конспекты уроков из Granola**, каждый вечер в 22:50 по Окленду. Берёт уроки дня из календаря, находит к ним заметки в Granola и добавляет конспект строкой в лист «Конспекты». Первый запуск забирает последние 30 дней: на бесплатном плане Granola старше не показывает. Строки только добавляются, существующие не меняются.
- **Посты для Instagram по урокам**, по воскресеньям в 09:49. Читает конспекты за неделю и пишет 1–2 черновика в лист «Посты»: без имён, оценок и личных подробностей учеников. Публикуете вы сами, из вкладки «Посты» в приложении.
