# Уроки и оплаты

Учёт предоплаченных занятий для частного преподавателя английского. Ученики платят вперёд пакетами по 4, 5 или 10 уроков, приложение держит баланс в уроках и в рублях, списывает проведённые занятия и подсказывает, кому пора напомнить об оплате.

С версии 3 приложение видит Google Calendar, показывает конспекты уроков из Granola, рисует обзор по месяцам и собирает черновики постов для Instagram. Проводить урок по-прежнему нужно вручную: календарь подсказывает, но ничего не списывает сам.

## Что умеет

**Учёт**
- Карточка ученика: имя, своя ставка, контакт, заметка, адреса в календаре, текущий баланс
- Оплата пакетом 4 / 5 / 10 или любым числом уроков, сумма считается по ставке
- Три исхода занятия: провёл, отмена со списанием урока, отмена без списания
- Отрицательный баланс с суммой долга, следующая оплата гасит его сама
- Блок «Пора напомнить об оплате» и готовый текст сообщения ученику
- Отметка нескольких занятий за день одним экраном
- История операций по каждому ученику с отменой последней записи
- Архив учеников

**Календарь**
- Блок «Ближайшие уроки» на неделю вперёд и следующий урок в карточке ученика
- Кнопки «Провёл» и «Отмена» прямо у урока из календаря; отметка запоминает, к какому событию относится
- При отмене приложение пишет, до какого времени ученик мог предупредить без списания
- Блок «Не отмечены»: уроки, которые прошли по календарю, а в истории их нет. Для каждого есть «Провёл», «Отмена» и «Не было»
- Групповые занятия: одно событие с несколькими учениками, каждого отмечаете отдельно
- Новые адреса из календаря привязываются к ученику кнопкой «Привязать»
- Импорт истории из календаря, подробности ниже

**Конспекты Granola**
- Конспект открывается прямо в строке урока, два последних видны в карточке ученика
- Конспекты переносит в Google-таблицу вечерняя задача Claude, приложение читает их оттуда

**Обзор**
- Уроки, проведено на сумму, получено, предоплачено и долг за текущий месяц
- График «проведено и получено» по месяцам с таблицей под ним
- Балансы учеников, неделя вперёд, уроки без конспекта

**Посты**
- Черновики для Instagram из листа «Посты»: слайды, подпись, хэштеги, статус
- Очередь в Telegram-канал: статус «одобрен» ставит пост в очередь, бот публикует по одному (docs/google-setup.md, раздел 6)

## Импорт истории из календаря

Настройки → «Загрузить историю из календаря». Приложение находит уроки за выбранный период, склеивает людей по адресам и именам (одна почта с двумя написаниями имени, опечатка в адресе) и предлагает, кто из них какой ученик. Новых людей можно создать учениками, давних сразу отправить в архив, отдельные даты снять галочкой.

Правило одно: **балансы не меняются**.

- Уроки **до начала учёта** у ученика добавляются в историю с нулевым списанием. Начало учёта: первая запись ученика, обычно «Стартовый остаток».
- Уроки **после начала учёта** не добавляются. Если рядом (±2 дня) есть ваша отметка, они только связываются с ней. Если отметки нет, урок попадает в блок «Не отмечены», и решаете вы.
- Повторный импорт ничего не задваивает.
- Перед применением приложение сверяет балансы до и после и отменяет импорт, если хоть один не совпал.

## Хранение и резервные копии

| Где | Что | Сколько |
|---|---|---|
| Redis на Vercel | текущее состояние и предыдущий снимок | всегда |
| Redis на Vercel | последний снимок каждого дня | 35 дней, восстановление из настроек |
| Google Drive | файл `uroki-ГГГГ-ММ-ДД.json` раз в день, папка «Уроки и оплаты: резервные копии» | 90 файлов |
| Браузер | копия при каждом изменении | на этом устройстве |
| Файл | «Скачать резервную копию» | сколько захотите |

Снимок отправляется на сервер через 0,7 секунды после последнего изменения. При закрытии вкладки несохранённое уходит через `sendBeacon`. Сервер отклоняет снимок без массива `students`.

Формат снимка совместим с версией 2: `students[].bal`, `h[]`, `thr`, `defRate`, `tplLow`, `tplDebt` читаются как есть. Новые поля: `students[].emails`, `students[].since`, `h[].at` и `h[].ev` (время и ключ события календаря), `h[].src: "cal"` у импортированных уроков, `dismissed`, `ignore`, `calWords`.

Режим артефакта claude.ai убран: приложение живёт на Vercel, а без сервера работает из файла `index.html` на `localStorage`.

## Запуск на Vercel

Проект подключён к репозиторию, каждый push в `main` выкатывает новую версию.

| Переменная | Зачем |
|---|---|
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Upstash Redis, ставит интеграция из Marketplace |
| `APP_PASSWORD` | пароль на вход; пока пусто, страница открыта всем |
| `GOOGLE_SCRIPT_URL`, `GOOGLE_SCRIPT_TOKEN` | веб-приложение Apps Script, см. [docs/google-setup.md](docs/google-setup.md) |

Без Google-переменных учёт работает как раньше, блоки календаря просто не появляются.

### Вход по паролю

- `/api/session` принимает пароль и ставит куку на 30 дней: `HttpOnly`, `SameSite=Lax`, `Secure` на https. Кука хранит только срок и подпись.
- Ключ подписи выводится из `APP_PASSWORD`, поэтому смена пароля разлогинивает все устройства.
- `/api/state`, `/api/google` и `/api/backup` без действительной куки отвечают `401`.
- Подбор упирается в счётчик: десять неудач за пятнадцать минут и дальше `429`.

Пароль защищает страницу, но не репозиторий. Репозиторий публичный: личные данные держите вне git, `.gitignore` прячет `seed*.json` и `*.local.json`. Все имена в тестах и демо вымышленные.

## Структура

```
src/app.html         стили и разметка
src/lib.js           чистая логика: сопоставление с календарём, импорт, конспекты, суммы
src/app.js           интерфейс и хранение
build.js             встраивает скрипты в страницу: index.html и public/index.html
api/state.js         чтение и запись снимка, копия за день
api/session.js       вход, выход и защита от подбора пароля
api/google.js        календарь, конспекты и посты через Apps Script
api/backup.js        список дневных копий, восстановление, копия в Google Drive
lib/auth.js          куки, подпись и сверка пароля
lib/store.js         доступ к Redis по REST
lib/days.js          дневные копии в Redis
lib/gas.js           вызов Apps Script с токеном
lib/body.js          разбор тела и параметров запроса
google/Code.gs       скрипт для таблицы «Уроки: конспекты и посты»
docs/google-setup.md подключение Google по шагам
docs/requirements.md требования и границы проекта
test/                тесты, см. ниже
```

## Сборка и тесты

```bash
npm install
npm run build   # src/ -> index.html и public/index.html
npm test        # сборка и все тесты
```

| Тест | Что проверяет |
|---|---|
| `test/lib.test.js` | логику без браузера: склейку людей, подсказки учеников, сопоставление событий с отметками, импорт без изменения балансов, конспекты, суммы по месяцам, Markdown |
| `test/gas.test.js` | `google/Code.gs` в песочнице с поддельными сервисами Google: токен, события из двух календарей, конспекты, посты, копии в Drive |
| `test/app.test.js` | учёт в Chromium: оплаты, отмены, долг, ставка, порог, отметка дня, резервная копия, обе темы, телефон |
| `test/import.test.js` | загрузку из файла и вставкой, разные формы JSON |
| `test/server.test.js` | хранение и вход целиком с поддельным Redis |
| `test/calendar.test.js` | календарь целиком с поддельными Redis и Apps Script: привязку, импорт, отметки из календаря, конспекты, обзор, посты, дневные копии, телефон и тёмную тему |

Playwright нужен только для тестов, Vercel его не ставит.
